# clases_leng4 · Artes del Lenguaje, Nivel 4: Dominio del GED y Escritura Argumentativa

Las **24 lecciones** del Nivel 4 de Artes del Lenguaje de GEDparaHispanos, pensadas para el **alumno que estudia por su cuenta**: cada lección explica, propone actividades con corrección inmediata y termina con su propio quiz. Están en español y siguen la preparación para el examen GED de Razonamiento a través de las Artes del Lenguaje (RLA).

## Cómo está organizado el repositorio

- `index.html`: índice del nivel.
- `bienvenida.html`: la primera página del nivel.
- `clase_T-N.html`: la lección N del tema T (por ejemplo, `clase_3-2.html` es la Lección 3.2). Cada lección es un archivo HTML autosuficiente, sin dependencias externas.
- `foto_final.jpg`: imagen del experimento de la luz que usa el Tema 6.

Cada lección enlaza con su **práctica interactiva**, que vive en el repositorio [`gramatica`](https://github.com/zhemaria/gramatica) con el nombre `n4-lT-N.html`. Las secciones de cada lección tienen anclas (`#s-…`) para poder enlazar una parte concreta.

## Accesibilidad

Las páginas siguen los principios del Diseño Universal para el Aprendizaje (DUA) y las pautas WCAG: lectura en voz alta con voz sintética en español, navegación con teclado, contraste suficiente, marcas que no dependen solo del color y avisos dentro de la página.
